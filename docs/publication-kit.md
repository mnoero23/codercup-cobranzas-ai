Primera versión estable y pública de Cobranzas AI, un proyecto de portfolio orientado a convertir una cartera abierta en una cola de trabajo explicable y gestionable.

#### Incluye

- scoring determinístico con cuatro factores auditables;
- prioridades Crítica, Alta y Seguimiento;
- explicación del aporte de cada factor;
- filtros por prioridad, estado y responsable;
- asignación, notas y compromisos de pago;
- historial de gestiones y exclusión de casos resueltos;
- borrador editable bajo revisión humana;
- datos sintéticos reproducibles;
- caso de negocio y capturas profesionales.

#### Validación

- 19 pruebas automatizadas aprobadas;
- 8/8 controles de calidad de datos;
- lint y formato aprobados;
- demo pública verificada en el flujo principal;
- persistencia de casos verificada.

#### Alcance

El scoring es una regla de decisión transparente, no un modelo predictivo ni machine learning. La aplicación no contacta clientes ni decide automáticamente: cada acción requiere revisión humana.

## Publicación para LinkedIn

Terminé Cobranzas AI, un proyecto de portfolio pensado desde un problema concreto de gestión: cuando el tiempo es limitado, ¿qué cuenta conviene trabajar primero, por qué y cuál es el siguiente paso?

La aplicación transforma una cartera abierta en una cola de trabajo priorizada. Combina saldo vencido, mora, uso del límite de crédito y concentración; explica el aporte de cada factor y permite registrar responsables, estados, notas y compromisos de pago.

El enfoque es deliberadamente transparente: el scoring es determinístico, no un modelo predictivo. La recomendación ayuda a ordenar la gestión, pero la decisión y el contacto permanecen bajo revisión humana.

El proyecto incluye una demo funcional en Streamlit, datos completamente sintéticos, persistencia e historial de casos, controles de calidad, pruebas automatizadas y documentación del caso de negocio.

Este trabajo representa el tipo de soluciones que busco desarrollar: combinar experiencia en control de gestión y finanzas con análisis de datos y automatización para resolver problemas operativos de forma simple y útil.

## Presentación breve para portfolio

### Cobranzas AI · Priorización y gestión explicable

Aplicación demostrativa para PyMEs que convierte una cartera abierta en una cola de trabajo priorizada. Integra scoring transparente, explicación de factores, acciones sugeridas y gestión operativa de casos con responsables, notas, compromisos e historial.

Fue desarrollada con Python, SQL y Streamlit sobre datos sintéticos reproducibles. El diseño mantiene a la persona en control: no predice incobrabilidad ni ejecuta contactos automáticos.

**Problema:** información dispersa y poco tiempo para decidir dónde concentrar la gestión.

**Solución:** priorización multivariable, trazabilidad y siguiente acción en un único flujo.

**Resultado:** demo pública verificable, 19 pruebas automatizadas y 8/8 controles de calidad aprobados.

**Demo:** https://codercup-cobranzas-ai.streamlit.app/
